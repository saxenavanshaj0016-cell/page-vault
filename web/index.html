    Viva explanation

    “The DBMS module keeps records in SQLite and groups ordered rows into logical pages. The OS module maps those pages to limited RAM frames. For each query it detects a page hit or page fault, retrieves a missing page, and applies FIFO or LRU when RAM is full. The dashboard makes these normally hidden operations visible.”
